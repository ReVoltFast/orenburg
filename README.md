# Открой Оренбуржье

Учебный многостраничный адаптивный сайт по заданию «Модуль А. Разработка интерфейса пользователя».

## Запуск
Откройте `index.html` в браузере. Для удобной локальной работы можно запустить любой статический сервер из корня проекта, например:
`python -m http.server 8000`
и перейти на `http://localhost:8000`.

## Страницы
- `index.html` — главная (светлая тема)
- `login.html` — вход
- `register.html` — регистрация
- `profile.html` — личный кабинет
- `catalog.html` — каталог
- `landmark.html` — страница достопримечательности
- `admin.html` — административная панель
- `index_dark.html` — главная (тёмная тема)

## Важно
Проект является статической вёрсткой HTML/CSS. Формы, фильтры и отправка данных не подключены к серверной логике. Интерактивные элементы, для которых это возможно в рамках задания, реализованы средствами CSS. Изображения в папке `media` — локальные векторные иллюстрации-заглушки, их можно заменить предоставленными медиафайлами.
